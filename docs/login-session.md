# 登录续期与记住密码

- 当前服务器访问令牌有效期 15 分钟，刷新令牌有效期 30 天。成功续期会轮换刷新令牌，并重新计算其有效期；长期不使用、撤销设备或账号停用需要重新登录。
- 启动时使用本地刷新令牌恢复登录。受保护请求在访问令牌到期前 30 秒进入续期，遇到 401 时也会续期并重试一次。并发请求共用正在进行的续期，避免同时消耗同一刷新令牌。
- 网络错误和服务器临时异常保留登录凭据，恢复网络后重试。服务器明确拒绝刷新或新访问令牌仍返回 401 时，清除失效会话、停止后台同步并打开登录窗口。本地日程、同步队列和冲突记录不删除。
- “记住密码”默认关闭。勾选且登录成功后，邮箱和密码通过 Electron safeStorage 系统加密写入独立的 remembered-login.bin，不写入普通配置文件。系统加密不可用时拒绝记住密码，不退化为明文。
- 凭据只用于对应服务器的登录表单预填，不自动提交；取消勾选立即清除记住的密码。不勾选登录也清除旧密码。退出登录会清除会话，但保留用户主动记住的密码。
- Windows 系统加密保护的是磁盘文件，不防范同一 Windows 账户下的恶意程序。共享电脑不建议记住密码。
