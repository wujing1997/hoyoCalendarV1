## 更新内容

### 日程助手

- 说法模棱两可的新增请求（如“提醒我吃晚饭”）会给出 2-4 个互斥方案供选择，例如不设时间、推测一个时间、每天重复；审批卡以单选呈现，只会写入选中的一个。
- 支持只改循环或长期任务的某一天（如“明天上班改成七点”），以及只跳过某一天（如“明天请假不去”），其余日期保持不变；被调整的那天在任务列表标注“本次已调整”，详情面板也会提示。
- 对已跳过的那天再做单次修改即可恢复该次。
- 助手对话内容现在可以选中复制。

### 手机推送（3.0.11 起）

- 新增 Bark 手机到时通知：设置 → 手机推送 · Bark。推送地址只保存在本机，不参与云同步。详见仓库 `docs/mobile-push.md`。

### 安装

- 程序文件名固定为 `HoYoCalendar.exe`，不再随版本号变化，升级始终覆盖同一份程序。
- 安装时会先关闭正在运行的旧版本（包括托盘中的），并清理旧版本遗留的 `HoYoCalendarV3.0.x.exe` 与对应卸载程序；保留的桌面和开始菜单快捷方式会改为指向新程序。
- 系统“应用”列表中的条目更新为 `HoYoCalendar 3.0.12`。

本版本包含此前仅在本地安装的 3.0.11 改进。

## 安装与使用

下载并运行 `HoYoCalendarV3.0.12-setup.exe`（Windows x64）。安装保留原有本地日程和配置，会自动关闭正在运行的旧版本。安装前建议备份重要日程。

“只改某一天 / 只跳过某一天”需要客户端升级到本版本：旧版客户端无法识别单次修改，会把它当作“从那天起”的修改执行。多设备使用时请把各设备都升级到本版本。单次调整随日程云同步，旧版客户端会忽略它，仍按原时间显示。
