# Bark 手机到时通知

设置 → 手机推送 · Bark，启用并填写 `https://api.day.app/你的推送密钥`，点击保存。仅支持官方 HTTPS 服务；密钥保存在本机配置中，不参与日程云同步，也不打进安装包。请勿把本机配置提交到版本库或分享给别人。

到时通知与桌面提醒共用日程判断：只提醒有具体时间的未完成任务，支持单日、重复、截止和长期任务；全天任务不发。截止任务使用截止日期，长期任务只在开始日提醒，重复任务按每次发生日期提醒。

推送包含任务标题、日期、时间和所属日历，分组为 HoYoCalendar，使用 POST 表单和 ttl=600。内容会发送给 Bark 服务，再由它推送到手机。桌面确认与手机发送互不影响，都不会改变任务完成状态。

首次启用或更换推送地址不补发此前的过时任务。启用后程序重启或电脑唤醒会补发当天遗漏的合资格任务，已成功提交的通知通过本地记录去重。临时失败从 5 秒开始退避重试，最多间隔 5 分钟；明确无效的密钥不反复重试。完成、删除或改期后，旧通知停止重试，已经提交的通知无法撤回。

电脑需保持开机且 HoYoCalendar 在前台或托盘运行；彻底退出、关机和休眠期间不能实时发送，唤醒后仅补当天。多个电脑若同时启用同一地址，可能分别推送，建议只在一台常开电脑启用。

接口返回成功只代表 Bark 服务已接收，不代表手机已经显示；仍需手机联网、允许 Bark 通知，并留意专注模式。超时可能发生在服务已接收之后，因此重试在极少数网络异常情况下可能产生重复通知。
